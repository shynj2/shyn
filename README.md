# Cyber Sanctum + Full Resume

این پروژه شامل سایت اصلی Cyber Sanctum و صفحهٔ رزومهٔ کامل شایان میرخانی است. هر دو صفحه استاتیک هستند و برای GitHub Pages آماده‌اند.

## انتشار روی GitHub Pages
1. محتوای همین پوشه را در ریشهٔ repository گیت‌هاب آپلود کنید؛ فایل `index.html` باید مستقیم در ریشه باشد، نه داخل یک پوشهٔ دیگر.
2. در GitHub به **Settings → Pages → Build and deployment** بروید.
3. گزینهٔ **Deploy from a branch** را انتخاب کنید، Branch را روی `main` و پوشه را روی `/(root)` بگذارید و Save کنید.
4. پس از انتشار، صفحهٔ اصلی در `https://USERNAME.github.io/REPO/` و رزومهٔ کامل در `https://USERNAME.github.io/REPO/resume.html` در دسترس خواهد بود.

## صفحه‌ها
- `index.html` — سایت اصلی Cyber Sanctum، نمونه‌کارها و صفحهٔ اصلی
- `resume.html` — رزومهٔ کامل و مستقل با طراحی، استایل‌ها و اسکریپت‌های داخلی
- `style.css` و `assets/` — فایل‌های سایت اصلی
- `assets/js/secret-data.js` — داده‌های رمزنگاری‌شدهٔ صفحهٔ مخفی، بدون تغییر

برای دیدن رزومه از صفحهٔ اصلی روی «Full Resume / رزومه کامل» بزنید. از صفحهٔ رزومه نیز لینک «Portfolio / سایت اصلی» به صفحهٔ اصلی برمی‌گرداند.

نکته: GitHub Pages برای سایت‌های استاتیک معمولاً انقضای ۳۰روزه ندارد؛ سایت تا وقتی repository و تنظیمات Pages فعال باشند منتشر می‌ماند.
